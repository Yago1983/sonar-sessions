# Sonar Sessions

Pages publiques des Sonar Sessions, organisées par Sonar Artists ASBL.

- `https://sonarsessions.sonarartists.be/` : page d'accueil, tous les événements.
- `https://sonarsessions.sonarartists.be/scan` : page ouverte par le QR code du roll-up (événement du jour, liens, don).

Les deux pages lisent la même liste : `events.js`. Pour ajouter un événement, on modifie uniquement ce fichier.

Ce dépôt est totalement séparé de la plateforme Sonar (sonar-front, sonar-back) et de son serveur.
